CodeElement

UMLClass
CougarScan View :: Domain :: Entities :: CodeElement

Description

Базовая абстракция для любой структурной единицы кода.

Хранит информацию об элементе:

  • name: имя элемента (идентификатор)
  • element_type: тип элемента (из ElementType)
  • location: позиция элемента в исходном коде

Бизнес-правила:

  • name не может быть пустым или None
  • element_type должен быть экземпляром ElementType
  • location не может быть None
